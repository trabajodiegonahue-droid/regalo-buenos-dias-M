# Regalo de buenos días 💌

Página con animaciones que pasa de escena en escena:

1. ☀️ Buenos días (sol saliendo)
2. 🌙 ¿Cómo dormiste?
3. 😊 ¿Cómo te sientes hoy? (eliges y te responde)
4. ✨ Frase motivadora (con botón para otra)
5. 💌 Cartita que se abre al tocarla
6. ❤️ Te amo mucho (toca el corazón)
7. 📱 Háblame cuando despiertes (botón a WhatsApp)

Se avanza con la flecha, tocando la pantalla o deslizando el dedo.

## Personalizar
Abre `index.html` y edita el bloque `const CONFIG` (nombre, firma, carta, frases y tu número de WhatsApp).

## Compartir
Activa GitHub Pages (Settings → Pages → rama `main`, carpeta `/`) y mándale el link.
